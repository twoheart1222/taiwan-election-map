# 政治觀察資料圖表

四分類圖表比較 2018、2022 年的歷史正式結果：議員投票率、議員參選人數、縣市長參選人數、議員實際當選席次。分析更新日期為 2026-11-04，不是新的選舉日期或最新民意調查。

## 建置

在專案根目錄執行：

```
node scripts/build-observatory-pages.mjs
```

此命令透過 `scripts/build-observatory-dashboard.mjs` 讀取兩份已核對的歷史整理檔，產生 `dashboard-data.json`（含輸入 SHA-256）與預設可直接閱讀的 HTML。它不讀寫候選人 API、後台或 KV。修改歷史輸入後應重新建置，並查核分析文字是否仍適用。

`dashboard-model.js` 的資料選取、數值格式與分析敘述同時供靜態建置和瀏覽器使用。`dashboard.js` 僅處理分類切換、篩選、排序、鍵盤操作與 CSV 匯出；資料載入失敗時保留既有靜態圖表、完整表格與分析。

## 統計與限制

- 全國投票率採全國投票數／選舉人數，不採縣市百分比直接平均。兩屆差異為兩位小數統計值的百分點相減。
- 議員人數與實際席次包含區域、平地原住民與山地原住民選區；跨屆選區可能不同。
- 首長參選人數由各縣市正式結果的 candidates 陣列計數；2022 嘉義市包含重行選舉結果，僅計一次。
- 席次採當選紀錄，與公告應選名額分開；使用 2026-10-30 更正後的 912、910 席。
- 圖表從零起算。投票率固定 0–100%；人數與席次的最大刻度依目前範圍調整，圖旁及方法區均有說明。
- 國家及縣市數值差異只描述結果；不據以推論因果、民意、政策表現或 2026 年勝負。每席參選紀錄比值不是個人當選機率。
