# 現任鄉鎮市民代表核對（2026-10-30）

來源：內政部地方公職人員資訊「鄉鎮市民代表」：
https://www.moi.gov.tw/LocalOfficial.aspx?n=575&TYP=KND0003

本次讀取 11 頁、2,043 筆不重複官方紀錄。代表會名稱漏列者，以同筆官方詳細頁的辦公地址確認鄉鎮；只保存公職身分及來源，不複製聯絡資料。這份來源不包括另列的直轄市原住民區代表名冊。

與目前候選人名單比對後，1,632 位可確認為同鄉鎮代表參選原職，135 位可確認為同鄉鎮其他職位或涵蓋原鄉鎮之議員選區參選。另有 17 筆同名候選人或既有轉職註記衝突不自動處理，274 位現任者未在可確認範圍找到唯一候選紀錄；不因此新增、刪除候選人，也不因未出現在本來源而移除既有現任標記。

- 原職：`isIncumbent: true`。
- 轉職：`isIncumbent: false`、`isCareerMove: true`，`priorRace` 填入目前官方職務（以「現任」開頭）。
- 兩類皆保存 `incumbentOffice`、`incumbentSourceUrl`。
- `isIncumbent` 代表參選原職，不能因為現在擔任其他公職就設成 true。
- 搜尋索引保留上述欄位；地圖、搜尋卡片及公開選舉頁顯示同一份候選紀錄。

`representative-incumbent-review-20261030.json` 保存核對紀錄、更新前的目標欄位與官方來源。重新比對：

```
npm run sync:moi-representatives -- --output work/representative-sync
```

預設只產生核對檔，不修改正式後台。確認新來源後才用 `--write-review` 更新本批核對檔；不要直接將未覆核的變動推送上線。後台「鄉鎮市民代表：現任與轉職核對」提供預覽及儲存，透過版本化 `/api/admin/overrides` API 整批更新。欄位已遭手動修改、姓名或職位比對不唯一、版本衝突時停止；不直接寫 KV。不在後台的地區會保留整份基礎名單後建立完整快照，版本使用 0。
